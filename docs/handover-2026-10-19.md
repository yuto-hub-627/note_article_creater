## 3. 口調と書き方

- note・Xともに全部、**口語調**（「〜してる」「〜だった」「〜っていう」）。オーナー自身の話し方に寄せる
- **人名は呼び捨て**（俳優・脚本家・演出家・アーティストすべて。「さん」は付けない）

- 避ける：「神ドラマ確定」「絶対面白い」などの断定、ほかの作品を下げて持ち上げる比較、俳優の見た目をけなす言い方、【】や煽り言葉で無理に目立たせること

## 4. 守るルール（著作権・人物・事実）

### 画像と文章

- **公式画像・場面写真・ポスター・キービジュアル・番組ロゴ・放送画面のスクショは使わない。** 場面や俳優を描き起こした絵（イラスト・AI生成）も使わない
- 公式のビジュアルを見せたいときは、公式サイト・公式Xのポスト・公式YouTubeのURLを1行で貼って、リンクカードで見せる
- 公式サイトやニュースの文章、他人のXのポストの文面は写さない。要約は自分の言葉で
- 台詞の引用は、必要なときだけ短く、第何話かを明記する
- **主題歌の歌詞は1行も引用しない。** 曲名はOK。音源を聞かせたいときは公式YouTubeのURLでリンクカードにする

### 人物

- OK：過去の出演作・役柄・受賞歴、本人が語った仕事の話、本人が番組やSNSで話した私生活（趣味・共演者との仲など）、役づくりでの見た目の変化やほめる話
- 噂は、面白ければ扱ってよい。ただし噂として書く（「〜と報じられている（媒体名・日付）」の形。事実のように言い切らない）
- 噂でもNG：評判を下げるもの（不倫・不仲・トラブル・素行）、犯罪・逮捕、病気・健康、妊娠、性的指向、本人が公表していない熱愛、一般人（家族・交際相手）が特定されること

### 事実確認とネタバレ

- 放送局・曜日・時間・初回日・キャスト・脚本家・原作は、公式サイトかニュースで確かめ、出典URLを残す。確かめられないことは書かない
- 放送前の作品は、公式が出している情報の範囲だけ
- ネタバレを含む記事はタイトルと冒頭に【ネタバレ】と書く。感想はその話までにする

### 行動

- **公開・投稿は、オーナーのOKをもらってから。**
- **他人へのリプライ・いいね・フォロー・DM・引用はしない。** 交流はオーナーが手でやる
- **Claudeはパスワードを入力しないし、ログインもしない。** ログインはオーナーがする。切れていたら作業を止めて、オーナーに知らせる

## 6. 作業の流れ

### note

- **毎日1本、18:00ちょうどに公開。** 前倒しは、オーナーが「今すぐ公開して」と言ったときだけ
- 記事の種類：①放送前ガイド ②1話感想（中心） ③週1の長い記事（まとめ・深掘り）。オーナーの依頼で2話以降の感想も出している
- 作り方：テーマ決め → リサーチ（いちばん大事） → 事実確認 → 執筆 → 貼れる完成品をオーナーに渡す（見出し画像・タグ・マガジンも）→ オーナーがnoteに貼って公開し、Xで告知する（10/19〜）→ 公開したURLをClaudeに伝える → 振り返り
- **タイトル案・告知案をオーナーに選ばせない。** Claudeが1つに決めて完成版を出し、数字を見て直す（ただし公開のOKはもらう）
- 1話感想の作り方：
  - ClaudeがXの声を集め、オーナーが共感したものに丸をつける。それをオーナーの意見として、ドラマ倶楽部の言葉で書き直す（他人の文面は写さない）
  - 考察は、**作品の背景（現実の問題・制作の背景）を事実で書く。** ラブコメの展開予想などは要らない（例外：kiDnap GAME 2話はオーナーの指示で、視聴者の考察を多めにした）
- 型：タイトルは作品名から始めて30字前後。冒頭50字くらいのリード、見出し多め。伸びている感想記事は2,400〜4,500字・見出し7〜11
- タグは5〜8個。作品名タグを入れる。#ドラマ感想文 は1アカウント1日1本しか付かないので、その日の計画上の感想記事に付ける（note 秋ドラマランキングの対象。#ドラマ感想文 か #テレビドラマ感想文 ＋番組名タグで、10/1〜10/31 集計）
- 作品ごとのマガジンに入れる
- 判断待ち：オーナーが見ていない作品の感想（10/14〜16 で4本）。「見た体験の文は書かない」で書いている。方針（オーナーが見た作品の感想）を変えるかはオーナーの判断待ち。編集長のおすすめは「見た感想のふりはせず、Xの反応＋作品の背景の記事として書いてよい」

### X

- **週1回。** 日曜に翌週分の一覧（文面と日時）を出す → オーナーがXの予約投稿に入れる（10/19〜）。放送休止・時間変更が見つかったら、Claudeがオーナーに知らせる
- note の告知文は note記事 が作り、オーナーが公開と同時に出す。ただし告知の型・数字・分析は X運用 がXのPDCAとして持つ
- 放送直後のひとこと感想と、返信・交流はオーナーが手でやる
- 投稿は1日3本まで、時間をあける。作品の公式タグは1〜2個
- 台詞1行＋解釈の投稿：台詞はXで集めた情報から取る（公式でなくてよい）。別々の2件以上のポストで同じ文言が確認できたものだけ使い、出典URLを残す
- リンクカードに古い公式画像が出たときは、URLの末尾に `?x=1` を付けると読み込み直される
- 固定ポストは、秋ドラマの一覧（自作の画像）

### 見出し画像（デザイン）

- 型：1280×670px。背景は作品のテーマカラー、中央に作品名（大きく、8字までなら1行、最大150px）、左上に「ドラマ倶楽部」、右上に放送枠（例「フジ 水22時」）、下に記事の種類（「第1話 感想」など）をアクセント色の帯に載せる
- **一番の制約：noteの一覧では96×50pxまで縮む。** そのサイズで作品名が読めるかで決める。主役の文字のコントラスト比は7:1以上
- 色はなるべく公式に寄せる。違いはフォントで出す（公式ロゴの形・配置はまねない）。同じ作品は何本でも同じ色。1枚に3色まで、大きな色面（斜めの帯・話数の透かしなど）を1つ
- フォントは商用OKのフリーフォントだけ（Google Fonts の OFL）。主役は太いもの。明朝は Noto Serif JP Black。「ドラマ倶楽部」と帯は Noto Sans JP Bold
- 作品が1つに決まらない記事（まとめ・3選）は、ドラマ倶楽部の色：背景 生成り `#F6EEDF`／文字 濃紺 `#1F2F4A`／アクセント マスタード `#E2A93B`
- 例：ポリティカルパンは深紅 `#A50F1C`
- 毎回、96px・211px に縮めたプレビューで読めるか確かめる
- 感想の見出し画像は、14作品の第1〜10話ぶんを作り置きした（10/15）
- 10/18 深掘りは「調査ファイル風」の見た目でオーナーOK。深掘り記事の型にするかは判断待ち

### PDCA と振り返り

- 何かを変えたら、根拠と結果を必ず記録する
- オーナーからの指摘（赤ペン）は記録し、**同じ指摘が3回出たらルールに格上げする**
- 毎週日曜に、全部署が週の振り返りを書く → 編集長がスライドにまとめる → オーナーがレビューする（1回目：10/11）
- 定時の仕事（10/19〜）：日曜にオーナーが数字を渡す → デザイン・note・Xの振り返り → X翌週分の一覧 → 編集長の振り返り→スライド。毎朝の数字の記録はやめる

## 7. 調べてわかったこと（根拠つきの学び）

### note

- 2026/2 のおすすめの刷新で、AIが記事を自動で分類し、読者ごとに出し分けるようになった。**人間の一次情報・体験が最優先。** 選者の視点がはっきりしたキュレーションは推されやすく、「Xの反応まとめ」のような他人の意見の焼き直しは推されにくい
- タイトルと見出し画像の差は、公開時刻の差よりずっと大きい（個人の検証で、クリック率に5.5倍の差）
- 公開時刻・曜日の差は小さい（個人の大規模調査。23時〜朝5時はやや低い）
- タグは5つ程度、内容に合うもの。意味の薄いタグは逆効果
- 作品名タグを付けると、作品ページ（AIが作る）に載ることがある
- 外部配信（SmartNews など）は設定でオン。X連携もオン
- **読者はXからではなく、note の中（タグ・検索・おすすめ）から来ている。** まとめ記事（10/4）は公開5日で645PV。Xは告知の表示が数回しかない

### X

- おすすめの重み：返信・URLコピーでの共有・プロフィールのクリックが強く、いいねは弱い。ミュートや報告は大きなマイナス
- 同じ作者の2本目以降は表示が減っていく → 投稿は時間をあける
- 伸びているドラマ系の個人アカウントの共通点：放送中〜直後1時間以内に集中、公式タグ1〜2個、プロフィールに外部媒体、保存される一覧・カレンダー（数十万〜100万表示）、台詞引用＋一言
- 伸びた感想ポストの形：1行目に「#公式タグ 第1話 感想」＋箇条書きの小ネタ／ひとつの強い意見を2文で／脚本家名で始めて過去作の小ネタ
- 本文にURLを入れると表示が減るという説があり、本文と返信を交互にしてテストした（結果はまだ出ていない）

## 9. うまくいかなかったこと（くり返さないために）

- ブラウザのログインがよく切れる（Claudeアプリの中のブラウザ。10/14 に note・X とも切れていた）。オーナーが入り直すしかない。対処の仕組みづくりは保留中
- 作業が止まった原因は、ほとんどが「仕組み」：OKを受け取るセッションが閉じていた、PCが止まっていた、ログインが切れていた。**止まったら黙らず、すぐオーナーに知らせる**

- note記事が見出し画像を自分で作ってしまった → 見出し画像はデザインの担当
- Xのアナリティクスはログインしていないと見られない。朝の記録が抜ける日があった
- 日本語の入力：Xの投稿欄は、キー入力の操作では日本語が入らないことがある（貼り付けで入れた）。noteのタグ欄は Enter で固まることがある（候補をクリックする）
