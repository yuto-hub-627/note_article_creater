# 運用のしくみ（2026-10-19〜 クラウド版）

ローカルで「部署＝別々のClaudeセッション」で回していた体制を、クラウドのClaude Code に合わせて組み直したもの。
方針・ルールは `docs/handover-2026-10-19.md` が正。このファイルは「どう回すか」だけを書く。

## 基本の考え方

- **オーナーとの窓口は、その日の1つのセッションだけ。** OKをもらう作業がセッションをまたがない。
  ローカル時代に止まった原因（OKを受け取るセッションが閉じていた・定時タスクでOKが取れなかった）をなくすため
- **部署は、セッション内のサブエージェント（役割）として動かす。** リサーチは作品ごとに並列で走らせ、執筆・デザインはメインで仕上げる。編集長の「指示だけ出す」はこの形で守る
- **部署どうしの連絡・方針・記録は、このリポジトリのファイル。** 次のセッションはファイルを読めば続きから始められる
- **オーナーがいない時間の定時の仕事（Routine）は、OKの要らない下ごしらえだけ。** 結果はファイルに置いて、通知で知らせる

## 1日の流れ（オーナーの時間：30分くらい）

進め方の細かい決まり（フェーズ・ゲート・レビュー表・記録）は `docs/aidlc.md`。下はその要約。

1. オーナーがセッションで「今日は○○と○○」と言う（または前日の予定どおり）
2. Claude：作品ごとにリサーチ（並列）→ 事実確認 → 執筆 → 見出し画像 → X告知文
3. Claude：入稿キット（タイトル・本文・タグ・マガジン・見出し画像・告知文・公開日時）を渡す
4. オーナー：読んでOK／赤ペン → Claude が直す
5. オーナー：18:00 に note で公開、X で告知 → **公開したURLを伝える**
6. Claude：`records/published.md` に記録、告知文のURLを確定

## 週5本の回し方（2026-10-31〜）

| 曜日 | 記事 | Claude | オーナー |

## 週の流れ（日曜）（〜10/30 の旧版）

| 担当 | やること |
|---|---|
| Routine（日曜の朝・自動） | 翌週の放送予定の確認（休止・時間変更）、Xの翌週分の投稿一覧の下書き、振り返りの下書き。ブランチにpushして通知 |
| オーナー | noteダッシュボード・Xアナリティクスのスクショか数字を渡す |
| Claude（セッション） | 数字を `records/` に記録 → 振り返り（note・X・デザイン）→ X一覧を確定 → 編集長の振り返りをスライドに |
| オーナー | 振り返りをレビュー、X一覧を予約投稿に入れる |

## フォルダ

| 場所 | 中身 |
|---|---|
| `CLAUDE.md` | 毎回自動で読み込まれる要点 |
| `docs/` | 引き継ぎ資料、このファイル |
| `articles/YYYY-MM-DD/` | その日公開する記事（`作品-話数.md`）と見出し画像（`作品-話数_header.png`、縮小プレビュー付き） |
| `research/` | 作品ごとのリサーチメモ（事実＋出典URL）。執筆とXはここにある事実だけを使う |
| `design/` | 見出し画像を作るスクリプト `make_header.py`、作品ごとの色 `shows.json`、フォント（Noto Sans JP / Noto Serif JP、OFL） |
| `x/` | Xの週ごとの投稿一覧 |
| `records/` | 公開記録・数字・赤ペン・判断の記録 |

## 見出し画像

```
python3 design/make_header.py <作品キー> "第1話 感想" articles/<日付>/<作品>-01_header.png [--mark 21]
```

- 新しい作品は `design/shows.json` に色と放送枠を足してから作る。色はこれまでの見出し画像と同じにする（同じ作品は何本でも同じ色）
- 96px・211px のプレビューも自動で書き出す。読めるか必ず確かめる
- ローカル時代の作り置き（14作品の第1〜10話）がオーナーの手元にあるなら、そちらを使ってもよい

## 入稿キット

```
python3 tools/build_kit.py articles/<日付> [articles/<日付> ...]
```

- `articles/<日付>/*.md` と `x/<日付>.md` から、コピーボタン付きのページ `kit/kit.html` を作る。Artifact として公開し、毎回同じURL（https://claude.ai/artifact/Q37113JeuZwsmG77ZMGuJ8）に更新する。放送後に仕上げる下書き（TODO が残っている記事）とそのX告知は出さない。放送が終わって結末と反響がそろった完成品だけを載せる
- 見出し画像のPNGは、チャットにファイルとして送る（Artifact のページからはダウンロードできないため）
