# 執筆ブリーフ（note記事担当のサブエージェント向け）

ドラマ倶楽部の感想記事を1本書くときの手順と型。最初に必ず読むもの：

1. `CLAUDE.md`（ルールの要点）
2. `docs/handover-2026-10-19.md` の 2〜4・6・7（切り口、口調、守るルール、記事の型、noteの学び）
3. お手本：`articles/2026-10-19/vivant-21.md`、`articles/2026-10-19/lost10-01.md`（口調・構成・長さ・出典の書き方をそろえる）
4. `research/schedule-2026autumn.md`（放送日と、各回のニュース記事の入口）

## 大前提

- **オーナーはこの作品を見ていない。** 「見てて泣いた」「正直つらかった」など、見た体験の文は書かない。書くのは、あらすじ（ニュースで確認できる範囲）、Xやニュースで報じられた反応、作品の背景（作り手・俳優・主題歌・現実の題材）の事実と、それをつないだドラマ倶楽部としての見立て
- 見立ては「〜っていう作りになってる」「〜が見どころになってる」のように、作品の作りについて言う
- **ほかのドラマ倶楽部の記事への言及やリンクは、同じ日に出す記事には張らない。** 前に公開済みの同じ作品の記事（1話感想など）へのリンクは末尾に1つだけ入れてよい（`records/published.md` のURL）
- 仮の文（「公開後に入れる」「TODO」など）は、完成稿には絶対に残さない。下書きで放送前に書けない部分だけ `TODO(放送後)：〜` と書く

## 事実

- 事実は公式サイトかニュース（モデルプレス、クランクイン！、オリコン、MANTANWEB、ザテレビジョン、リアルサウンド、スポーツ紙など）で確かめる。Wikipedia・まとめサイト・個人ブログだけの話は使わない
- 反応は、ニュースが報じたXの反応を要約する（他人のポストの文面は写さない。ニュース記事が引用した短い声を「」で1〜3語程度ならOK、媒体名を添える）
- 台詞は必要なときだけ短く。歌詞は1行も引用しない
- 人物：評判を下げる噂・病気やけが・恋愛・家族の話は書かない（例：ボーダーズの眞島秀和の降板は「5話から中村俊介が役を引き継ぐ」という事実だけなら書いてよい。理由のけがには触れない）
- 視聴率はニュースで報じられたものだけ
- 調べた事実と出典URLは `research/<作品キー>.md` に書く（形式は `research/lost10.md` と同じ）

## 型

- 冒頭：`【ネタバレあり】この記事は『作品名』第N話（M月D日放送）の内容に触れてます。` → 50字くらいのリード → 公式サイトURLを1行 → 基本情報（局・枠、出演、脚本・演出・原作、主題歌）
- 見出し（`## `・`### `）は合計7〜11。本文は2,400〜4,500字
- 切り口は作り手・俳優・主題歌のうち最低2つ
- 最後は「まとめ」の箇条書き → 「みんなはどう見た？」の問いかけ → （あれば）同じ作品の前の記事へのリンク → 「この作品の感想は、マガジンにまとめていく。」
- 人名は呼び捨て。口語調（「〜してる」「〜だった」「〜っていう」）。断定・煽り・ほかの作品を下げる比較・【】で目立たせる、はしない（冒頭の【ネタバレあり】だけ例外）

## ファイルの形式

`articles/<公開日>/<作品キー>-<話数>.md`（例：`articles/2026-10-22/minamida-01.md`、まとめは `moupapa-01-03.md`）

```
---
公開: 2026-10-22 18:00
タイトル: 作品名 N話 感想｜（ひとことで内容）（ネタバレ）
タグ: "#作品名 #作品名第N話 #ネタバレ #テレビドラマ感想文 #（俳優や脚本家） #（枠名など） #ドラマ倶楽部"
マガジン: 作品名 感想まとめ
見出し画像: <作品キー>-<話数>_header.png
---

本文
```

- タイトルは作品名から始めて30〜35字
- タグは5〜8個。`#作品名第N話` を入れる（まとめ記事は最新話の番号）。`#ドラマ感想文` は付けない（その日の1本に、こちらで付ける）
- 本文の中のURLは、行にURLだけを書く（noteでリンクカードになる）
