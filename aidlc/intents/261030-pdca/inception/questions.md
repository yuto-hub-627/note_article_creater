# オーナーに決めてもらうこと（ゲート1）

1. 記事の型：A（話題作の毎話）＋B（週のまとめ）＋C（深掘り）で、週5本前後に減らしてよいか
   - 毎話感想を続ける作品：VIVANT だけ／VIVANT＋もう1作（数字を見て決める）／いまの12作品のまま
2. 公開：1日1本・決まった時刻でよいか。時刻はいつがいいか（例：21:00）
3. 数字：毎週日曜に、note の「アクセス状況」（週）と X アナリティクスのスクショを貼ってもらえるか
4. 見た回：オーナーが見ている作品があれば教えてほしい（1〜2行の感想を入れると、noteで一番強い）
5. いま作り置きの記事（アナログナース 2話・めおと 3話、メリー 4話・ポリパン 4話）は出し切ってから切り替えるか、ここで止めるか
